# UsageBar AppIcon

The approved artwork is stored at `IconSource/UsageBar-1024.png`.

`ChatGPTUsage/Assets.xcassets/AppIcon.appiconset` contains the standard macOS sizes: 16, 32, 128, 256 and 512 points at 1× and 2×. The 512pt 2× slot uses the full 1024×1024 source. The Xcode target compiles this catalog as `AppIcon`.
